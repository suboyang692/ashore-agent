# 研岸批改评测标注规范 v1

> 目的：统一人工标注与模型判定的标准，避免"同一作答被判成不同错因"的歧义。
> 原则：**先判对错（通过/不通过），再判错因**；错因不影响得分判定。

## 一、错因分类定义

| 类别 | 定义 | 典型特征 | 得分区间 |
|---|---|---|---|
| 方法误用 | 选择了不适用或错误的解题方法 | 求极限却用分部积分 | 0-20 |
| 审题错误 | 看错条件、漏看要求 | 求极小值却算成极大值 | 0-30 |
| 知识点不熟 | 核心概念、定义或公式本身记错 | 分部积分公式记成 uv+∫vdu | 0-30 |
| 计算错误 | 方法与公式正确，但数值/符号/代数运算出错 | 符号写反、加减乘除算错 | 10-50 |
| 结论跳跃 | 有正确结论但缺少关键推导步骤 | 只写答案不写过程 | 40-59 |
| 表述不规范 | 答案正确但书写不规范 | 漏写 +C、漏写定义域 | 70-85 |
| 无错误 | 答案正确 + 方法正确 + 关键步骤完整 | 有推导、有中间结果、有结论 | 90-100 |

## 二、"关键步骤完整"的判定口径（最易产生歧义）

**算完整**（判无错误）：
- 写出所用方法名称（如"分部积分""泰勒展开""洛必达法则"）
- 给出关键中间结果（如展开式、驻点、原函数）
- 给出最终结论

**不算完整**（判结论跳跃）：
- 只有最终结论，没有任何方法或中间过程
- 有方法名称但没有中间结果，直接跳到结论

**允许省略的细节**（不因此扣分）：
- u、v 的具体选取过程
- 中间代数变形的每一步
- 积分常数 C 的中间书写（但最终答案必须含 C）

## 三、判定优先级（边界案例）

方法误用 > 审题错误 > 知识点不熟 > 计算错误 > 结论跳跃 > 表述不规范

即：一个作答同时符合多类特征时，选优先级最高的那一类。

## 四、通过/不通过标准

- 得分 ≥ 60 判通过（is_correct=1），< 60 判不通过
- 只有最终结论正确但无过程：判**不通过**（结论跳跃，40-59 分）

## 五、标注一致性要求

1. 同一作答重复批改 3 次，判定结果应一致；不一致的样本需在 dataset 中记录并说明
2. 每条样本必须写清 rubric 依据，便于复核
3. 新增样本前先对照本规范，避免个人偏好差异

## 六、v1.1 修订（评测后迭代）

依据 18 条样本首轮评测结果修订：

1. **分数区间与通过线对齐**：结论跳跃改为 40-59，避免 60 分卡在通过线上导致误判。
2. **"关键步骤完整"口径强化（最重要）**：满足「方法名称 + 关键中间结果 + 结论」三点即判无错误。
   以下缺失**不扣分**：未写 u/v 选取、未逐步代数变形、未说明余项阶数、未验证方法前提条件。
   （首轮评测中 3 条错判均源于把"过程简略"误判为"结论跳跃"）
3. **错因判定顺序化**：按"方法是否适用 → 是否审题错 → 公式是否写错 → 是否运算错 → 是否缺过程 → 是否书写不规范"依次自问。
4. **公式写错 vs 运算出错**：明确规定"写错公式本身"= 知识点不熟；"公式对但代入算错"= 计算错误。
